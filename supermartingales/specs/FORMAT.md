# frozen benchmark spec format (wave 0)

One TOML file per benchmark instance. Primary specs are named `<benchmark>.toml`
(what wave 1 synthesizes against); alternate candidate reconstructions are
`<benchmark>__<tag>.toml`, each self-contained. Extracted table cells live in
`../manifest.toml` and are never edited here (0-cell-error property preserved;
this format *extends* the manifest with executable dynamics).

## Program model

Every row of the paper (arXiv 2301.06136 v7) is a loop

```
while GUARD do assert(ASSERT); BODY od
```

State classification at loop head (this is the exact-chain semantics):

- **active**: `GUARD && ASSERT` — BODY runs (one probabilistic step);
- **bad** (violation, the reach target): `GUARD && !ASSERT`;
- **safe** (termination): `!GUARD`.

`P[reach bad | init]` is the quantity all published bounds bound.

## Fields

```toml
[benchmark]
name = "faulty_loop"
family = "unreliable_hardware"        # their taxonomy
section = 3                           # their Table-1 grouping
provenance = "listing | reconstruction"  # + free-text citation (page/line)
state = ["i", "error"]                # ordered state variables
reals = []                            # subset of state that is real-valued (default: integer)
init = {i = 1, error = 0}
guard = "i < 10"                      # boolean expr over state
assertion = "error == 0"

[[benchmark.dynamics]]                # first-match region list (piecewise dynamics)
region = "true"                       # boolean expr over state
branches = [                          # exact mixture; probs are rational strings, must sum to 1
  {prob = "1/1000",   update = {error = "1"}},
  {prob = "999/2000", update = {i = "i + 1"}},
  {prob = "999/2000", update = {}},   # empty update = stay
]

[benchmark.noise]                     # optional; noise vars usable in update exprs
u = {dist = "uniform", lo = "-2", hi = "1"}     # continuous U[lo,hi]
# u = {dist = "duniform", lo = "-2", hi = "1"}  # discrete uniform on integers lo..hi

[benchmark.farkas]                    # the reverse-engineered LP their Farkas' column solved
published = "0.0181"                  # exact decimal string from manifest (or "none")
grid = {i = [0, 10], error = [0, 1]}  # integer enumeration box for LP constraint generation
invariant = "0 <= i && i <= 10"       # nonneg domain I (their per-row manual invariant)
target = "error >= 1"                 # A-region (V >= 1 imposed on target && invariant)
objective = {i = 1, error = 0}        # state whose V-value the LP minimizes
note = "free text: which convention frame this is and why"

[benchmark.truth]
method = "chain"                      # chain | mc | both | none
mc = {n = 4000000, t_max = 4000, seed = 461}   # only read when method uses mc
```

## Expression language

Affine-ish arithmetic over state + noise variables: `+ - *` with rational
constants (`1/2`; `0.999` is *not* allowed — write `999/1000`; exactness
matters), comparisons `< <= == >= >`, boolean `&& || !`, literal `true`.
The producer harness evaluated these exactly over rationals (python
`fractions.Fraction`, ast-based, no `eval()`) and compiled the same ASTs
to `jax.numpy` for the Monte-Carlo cross-instrument; that harness is
part of the producer layer migrating to TypeScript on the modelling
toolkit's public API. The stored certificates and their manifest pins
are independent of it.

## Representation-agnosticism (2026-07-18)

Specs freeze DYNAMICS + SETS only. Nothing here commits wave-1 synthesis to a
certificate representation: {per-cell polynomial, ReLU-hypernet (Cell/Contract
+ ReLU/PLiRPA rules), exact-VI export} are all open per row. The `[farkas]`
block is a reproduction of THEIR baseline LP (a fingerprint instrument), not a
template choice of ours. Region atoms are boolean affine conjunctions —
representation-neutral.

## The Farkas-LP fingerprint

The LP: linear template `V(s) = sum_v a_v * s_v + c`, constraints generated by
enumerating all integer points `s` of `grid`:

- `s ⊨ invariant && target`  →  `V(s) >= 1`
- `s ⊨ invariant && !target` →  `V(s) >= 0`
- `s ⊨ guard && assertion && !target` (active) → `E[V(step(s))] <= V(s)`
  (exact expectation; successors evaluated by the template's linear extension —
  points outside `invariant` are *not* clamped: their own published cliff
  certificate surface pins this convention)

For real-valued rows the integer grid is still exact: all constraints are affine
in `s`, and every region/invariant boundary in this suite is integral, so
binding points are grid points.

Match criterion (exact, no float-close): `ceil(opt * 10^4) / 10^4 == published`
as `Fraction`s. The ceiling convention is pinned three ways: 10/101 → 0.0991
(repulse100), 5/11 → 0.4546 (cliff), 2/111 → 0.0181 (faulty_loop); round-nearest
reproduces none of the last digits.
